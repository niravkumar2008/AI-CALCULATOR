  • The free first month costs you about $1.50–4 in API per buyer. Cheap, and it gets every buyer linked and using it.
  • Set a fair-use cap of about 500 solves a month, so a heavy user can never cost more than they pay.
  • Offer a yearly plan at about $150 (two months free). It brings cash in earlier and keeps people longer.
  • Bill through Stripe on your own site or companion app, not an app store, so you keep the 30 % an app store would take.
  • The calculator without a subscription should still work as a normal scientific calculator. That keeps the $225 fair and avoids "bricked device" complaints.

How the $2,000 compounds estimate

Each batch's sales pay for the next, bigger batch. Take preorders with deposits before each build, so customers fund the parts. Two hard rules: no sales until the FCC test (SDoC) is done, and use your own shell, not Casio's (§4).

5 · Path to "it makes itself"

Stage 1 · 2–10 units

Now

JLCPCB builds the boards. You assemble, test and ship.

You: everything

Stage 2 · 10–100

Test jig

3D-printed pogo-pin bed (≈ $50–150 estimate) + a PC script: flash → self-test → serial number → PASS/FAIL label.

You: one button per board, about 2 min

Stage 3 · 300–1,000

Turnkey + 3PL

An EMS builds and runs your jig and sends you a CSV of results. A 3PL or FBA ships to customers.

You: supplier email, spot checks, firmware

Stage 4 · 3,000+

Contract manufacturer

Parts, molding, PCBA, assembly, test, packing, sea freight to FBA.

You: roadmap, OTA updates, marketing

Build these in order

  • Factory test firmware (start 10/10): one boot mode that checks everything and prints JSON over USB.
  • Test pads: 3.3 V, GND, EN, IO0, D+/D−, VBAT. Tonight's stage-11 work already adds bring-up test points. v2 puts them in a pogo-jig pattern.
  • Automated flashing: esptool + Python. Each board gets a unique ID and proxy token when it's flashed.
  • Signed OTA updates (two app slots), so bug fixes don't need returns.
  • The proxy becomes the fleet backend: subscriptions, usage caps, crash logs.
  • Support: FAQ, help email, AI-drafted replies. Budget 2–5 % of units needing help estimate.
