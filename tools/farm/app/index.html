How it keeps going

  • Closing this window doesn't stop the farm. It keeps working in the tray (the sprout icon by the clock). Right-click it to pause or quit.
  • Quit (tray menu) stops the farm. Start with Windows brings it back at every login.
  • The farm works while Windows is logged in and awake. Set sleep to "Never" when plugged in for overnight work.
  • Wi-Fi drops are handled by the Wi-Fi watchdog: runs wait and retry without using a try.
