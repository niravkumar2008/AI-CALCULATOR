First Power-Up Guide

Do these steps in order, one at a time, the day the JLCPCB boards arrive. Every check is there to catch a fault before it can hurt the board. Tick each box as you go; ticks are saved in this browser only.

Five rules for the whole day

  1. If anything gets warm, smells, or a reading is wrong: unplug first, think second.
  2. Never plug or unplug a ribbon (e-paper, camera) while the board has any power. Once the battery is in, the board is always powered, so ribbons go in before the battery. general practice
  3. First power comes from a computer USB port, not a phone charger. A computer port cuts the current quickly on a fault; a charger may push 2 A or more.
  4. Never connect the battery until its polarity has been metered (step 4).
  5. Never burn eFuses, enable secure boot or flash encryption. They are the only things that can lock you out for good.

01What you need

Test points on the board, all on the component side, labelled on the silkscreen: TP1 BOOT TP2 TX TP3 RX TP4 GND TP5 3V3 TP6 BAT TP7 EN. The black meter probe goes on TP4 for every voltage reading below.

02Inspect the bare board

Unpowered, under good light (a phone camera zoomed in works). Hold it like the render: component side up, top edge away from you.

If a part is turned the wrong way or bridged: don't power it. Photograph it and ask.

03Magnet piece check, before gluing

J3 is wired, from pin 1 (silk N and +, leftmost pin seen from the component side, top edge away from you): VBUS, D−, D+, GND. The last pin has the silk −.

Why: fitted backwards, the cable's 5 V lands on the board's GND. A computer port cuts the current quickly, but a phone charger can push 2 A or more through D7 and the charger chip and damage them. Never test that on purpose.

04Battery polarity

Q1 protects the board from a reversed cell, but with USB also plugged in a few mA would flow into the reversed cell. So: polarity first, always.

05Camera ribbon beep test

While the camera is out: measure its ribbon from the module's far edge to the tip and note it. Under about 70.3 mm means tape the module up to 1.7 mm towards J1 and drill the 7 mm window where the lens actually sits.

06First power: USB only

Nothing else connected: no battery, no display, no camera. Magnet piece pushed into J3, cable into a computer USB port. Keep one hand on the plug.

The VBUS range is the normal USB range, not a board figure. SYS is VBUS minus D1's drop. A few tenths of a volt off on VBUS/SYS is fine; +3V3 should be inside its range.

Wrong reading or hot part: unplug, let it cool, don't plug in again "to check". Note which part was warm and which reading was off, then ask.

07Flash the firmware

The first flash is always over USB, on every board: a new board is blank, and this firmware uses a two-slot partition table (min_spiffs.csv) so that later versions can arrive over the air. An over-the-air update only replaces the app in the other slot; it can never write the partition table, so the first flash (and any future partition change) must be this USB upload. After it, status and the self-test show app0; the first over-the-air update moves to app1 (firmware-prototype/README.md §4).

If no COM port appears, or "no serial data"

With a battery connected later, plugging the cable in does not reset the chip, so holding BOOT while plugging in does nothing. Use the TP7 tap (or unplug the battery first). Last resort: a 3.3 V USB-serial adapter on TP2 (TX) / TP3 (RX) / TP4 (GND), then the same TP1 + TP7 sequence. In deep sleep the USB port disappears: press ON to bring it back.

10Connect it to the AI server

The maths works without any of this. For AI SOLVE the calculator needs three things: a phone hotspot (2.4 GHz), the address of your AI server (the proxy in server/proxy) and its own device token. The Claude API key lives only on the server. The calculator never holds it: the token command refuses anything starting with sk-ant-.

Once: put the server online (about 30 min, best while you wait for the boards)

Per calculator: make its token

Put the settings in the calculator (cable in)

Screen messages: Not set up yet: SETUP 6 = address or token missing. NO CONNECTION = the hotspot is off or not 2.4 GHz. AI ACCOUNT = not linked yet, trial over, or the monthly cap (the server's own sentence is shown). Battery low: plug in the cable to use AI solve = the cell is under 3.6 V: camera and Wi-Fi stay off until it is back above 3.7 V or a cable is in; maths keeps working. Later firmware versions reach the calculator over the air from this server (firmware-prototype/README.md §4, server/proxy/README.md).
